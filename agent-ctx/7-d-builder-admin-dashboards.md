## Deviations / decisions

- Split admin into `admin/parts-*.tsx` (allowed by spec) — 10 tabs in one file would be ~3,000 lines. Builder dashboard also imports primitives from `admin/parts-shared.tsx` (my file, no rule violation) to avoid duplication.
- `useDashboardTab` derives the active tab **directly from the store route query** (URL is single source of truth) instead of mirrored state — required by the new `react-hooks/set-state-in-effect` ESLint rule which bans synchronous setState-in-effect (also restructured `useApiData` fetch and page-reset-on-filter logic into event handlers for the same reason).
- Project amenities sent as comma-separated **string** (ProjectDetailDTO.amenities is `string | null`); property amenities sent as `string[]` per contract.
- UnitForm includes city/locality/address (required by POST /api/properties contract) auto-filled from the selected project.
- Transactions table shows no image thumb (TransactionDTO.property has no mainImage field).
- Removed `@next/next/no-img-element` eslint-disable comments in MY files — the rule is not enabled in this project's config, so the directives produced "unused directive" warnings. (Same warnings still exist in shared/* files owned by other agents — untouched.)
